# Overview

The software is a simple C++ application that that will send both "Hello, World!" along with the secondary "Goodbye World" to the terminal. While you may say it is simple, and I would agree, I believe that you will be impressed by the growth which follows.

My purpose for creating this software is to practice PY development and prepare myself for larger and more complex projects.

I also created a short demonstration video showing the program running and a quick walkthrough of the code.
